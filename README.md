# Gruppengenerator
Web-App für den Unterricht: Sie bildet zufällige Gruppen oder zieht einzelne Kinder aus einer Klasse. Dabei beachtet sie Regeln, die die Lehrkraft vorher festlegt. Die Kinder sehen diese Regeln beim Mischen nicht.

- Läuft auf iPad, PC und jedem modernen Browser, nach dem ersten Öffnen auch ohne Internet
- **Alle Schülerdaten bleiben auf dem Gerät** (Browser-Speicher). Es werden keine Daten übertragen.

## Funktionen

- **Klassenverwaltung:**
  - Kinder mit Geschlecht, Leistungen je Fach (3 Stufen oder nur „stark“) und eigenen Merkmalen wie DaZ oder Förderbedarf
  - Namenslisten per Kopieren und Einfügen übernehmen
- **Paarungen:** „Nicht zusammen“ und „Zusammen“, auch für mehrere Kinder auf einmal
- **Vorlagen**, die am Vortag vorbereitet werden:
  - Gruppengröße oder Anzahl der Gruppen
  - Mädchen und Jungen ausgleichen
  - Leistungsstarke Kinder verteilen oder Niveaugruppen bilden
  - Merkmale verteilen
  - Abwechslung gegenüber früheren Gruppen
  - Rollen
- **Im Unterricht:**
  - Klasse wählen, fehlende Kinder abhaken, Gruppengröße bei Bedarf anpassen
  - Mischen mit Animation
  - Kinder per Finger zwischen Gruppen verschieben
  - Drucken
- **Rollen:**
  - Jede Gruppe bekommt alle gewählten Rollen. Kinder, die länger keine Rolle hatten, kommen bevorzugt dran.
  - Mehrere **Rollensets**, z. B. für Deutsch, Englisch oder Mathe. Jede Vorlage wählt ihr eigenes Set.
- **Mischanimation:** In der Verwaltung unter „Anzeige“ wählbar:
  - „Standard“: Die Namen wirbeln sofort durcheinander.
  - „Mit Vorschau“: Die Namen erscheinen zuerst ca. 2 Sekunden geordnet.
- **Einzelauswahl:** zieht ein Kind, optional so, dass jedes Kind erst einmal drankommt
- **Sicherung:** Export und Import als Datei
